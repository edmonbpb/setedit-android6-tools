# راهنمای فارسی

این مخزن فقط **ابزار و راهنما** است. فایل نصب برنامه اینجا نیست؛ برنامهٔ اصلی مالِ نویسندهٔ آن است و بازنشرش نمی‌شود.

## این ابزار چه می‌کند

- بستهٔ تکه‌تکهٔ اندروید (`.apks`) را به یک فایل نصب تبدیل می‌کند.
- در صورت نیاز، سطح هدف را پایین می‌آورد تا اندروید ۶ اجازهٔ «تغییر تنظیمات» را از همان اول بدهد.
- صفحهٔ شروع را جابه‌جا می‌کند تا کاربر روی صفحه‌ای که به کامپیوتر نیاز دارد گیر نکند.
- فایل را تراز و با سه روش امضا می‌کند تا اندروید ۶ قبولش کند.
- در پایان، نتیجه را بررسی می‌کند.

## پیش‌نیازها

- جاوا ۱۷
- ابزارهای ساخت اندروید (`zipalign`، `apksigner`، `aapt2`)
- فایل `APKEditor` (مجوز Apache-2.0)
- پایتون ۳ برای دو اسکریپت کوچک

## استفاده

```bash
export ANDROID_BUILD_TOOLS=/path/to/build-tools/36.0.0
export APKEDITOR=/path/to/APKEditor.jar
export KS_PASS=your-keystore-password

scripts/build.sh -i app.apks -o app-android6.apk \
  -k my.keystore -a mykey \
  --target-sdk 22 \
  --launcher-to com.example.app.MainActivity
```

## نکتهٔ مهمی که در ساخت اولیه دردسر شد

اگر کل بسته را با ابزار تغییر بدهید و از نو بسازید، بخشی از تصویرهای متحرک خالی می‌شوند، هرچند همهٔ شناسه‌ها و مسیرها یکی می‌مانند.
راه‌حل بررسی‌شده: فقط فایلِ تنظیماتِ اصلی را از نسخهٔ بازساخته بردارید و به فایل ادغام‌شده منتقل کنید؛ بقیهٔ منابع دست‌نخورده می‌مانند.

## محدودیت‌ها

- تغییر جدول‌های امنیتی و سراسری به بستهٔ کمکی و یک اجازهٔ یک‌باره با کامپیوتر نیاز دارد.
- نسخه‌ای که سطح هدفش پایین است، روی اندروید ۱۴ و بالاتر نصب نمی‌شود.
- امضای تازه یعنی نسخهٔ قبلی باید حذف شود و به‌روزرسانی فروشگاه دیگر نمی‌آید.

**مسئولیت استفاده و هر تغییری که روی گوشی می‌دهید با خودتان است؛ هیچ ضمانتی وجود ندارد.**
